# JWT decoder

Simple .NET WinForms application that you can paste a JWT bearer token into and see the header and body decoded.
This is great when developing API's to check that the correct claims exist in the token or for just checking how much longer you have on a tokens expiry time.

This was developed to avoid posting token data onto websites to achieve the same result.
